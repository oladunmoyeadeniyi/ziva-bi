## Blocking finding: `tsc --noEmit` fails — `appName` used outside its component scope
```
src/app/platform/tenants/page.tsx(243,63): error TS2304: Cannot find name 'appName'.
```
I mapped every `appName` reference in the file:
```
14:  import { useAppConfig } from "@/contexts/AppConfigContext";
94:  function CreateCompanyModal({ ... }) {          ← separate component
243:    ...Mark as a {appName} internal company...   ← BROKEN: no useAppConfig() call in this component
370:  export default function PlatformTenantsPage() {
372:    const { appName } = useAppConfig();          ← hook is called HERE
433:    ...All tenants on the {appName} platform...  ← correct: same component as line 372
```
`useAppConfig()` was added to `PlatformTenantsPage` (the default-export, line 370-372), but
`{appName}` is also used at line 243 inside `CreateCompanyModal` — a separate function component
defined earlier in the same file. React hooks are scoped to the component they're called in;
`CreateCompanyModal` has no access to a variable from a sibling component. This is the same class of
mistake as an earlier round's model mix-up in this project's history: an edit landed in the right
*file* but the wrong *scope*.

**Fix:** add `const { appName } = useAppConfig();` inside `CreateCompanyModal`'s own function body
(it's a Context-based hook, so no prop-drilling is needed — just call it again in that component).
