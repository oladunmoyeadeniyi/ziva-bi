## Architectural notes (non-blocking)

Worth a follow-up: add `import logging; logger = logging.getLogger(__name__)` and a `logger.warning("OCR service error: %s", exc)` call before raising the generic `HTTPException`, so operability isn't sacrificed for the (correct) security fix.
